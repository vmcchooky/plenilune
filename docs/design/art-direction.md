# Art direction

Thesis: make exact configuration comparison read like a calm change review desk.
Archetype: Dark Precision, adapted to paired light/dark neutral surfaces and teal.
Brand ingredient: the before/after source pair; the moon mark remains recognizable.
Signature: an asymmetric verdict/overview pair, followed by an equal source pair.
Typography: system Segoe UI for Vietnamese coverage and offline delivery; Cascadia
for actual code/hash data only. Display weight 500, negative tracking; no remote fonts.

Material studies considered: (1) existing pastel/serif, (2) neutral teal desk,
(3) near-black monochrome. Selected 2: colors can still encode verdict meanings.
Composition studies: (1) inputs first, (2) results first after analysis. Selected 2
following the first screenshot review; source editors remain directly beneath.
The moodboard shows the selected material and these alternatives.

Reference basis: ui-styles catalog Dark Precision recipe (secondary analysis, no
new claims of measurements from Linear); actual prior product captures in references/.
No new live external reference collection or calibrated human taste panel was run.
This is the skill's quick path for an existing tool. These full-L phase criteria
remain unfulfilled and are not represented as approved.

Forbidden: decorative gradients/glow; verdict indicated by color alone; equal KPI
cards or decorative mono labels. Semantic colors remain tied to labeled results.

## Refined material after owner rejection

The earlier teal surfaces/edges and emphasis effects were not accepted. Current
material is cool neutral gray, flat surfaces, one subtle line scale, neutral primary
actions, color only in explicit status/focus/link roles. See style-recipe.md for
current dimensions; the first material study is historical, not an approved golden.

## Owner palette direction · 02/11/2026

The owner specified light as the primary mode, a beige/cream base, gentle accents,
and fewer hues with tonal component separation. Apply the cream neutral recipe
with one muted olive accent. Keep system sans and data typography for this tool.
Earlier cool gray/dark palette notes are historical. Current values are in
style-recipe.md and runtime tokens. Light stays stable under either OS preference;
no theme toggle or automatic dark switching is introduced in this pass.
