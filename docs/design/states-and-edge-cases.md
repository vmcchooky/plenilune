# State matrix

| Surface | States / recovery |
|---|---|
| Source | Synthetic sample, modified sample, blank, one source, two sources, import error, parsing, canceled. Preserve exact import bytes and manual retry. |
| Result | DIFFERENT / EQUIVALENT / INCONCLUSIVE, partial, unsupported object, no selection, multiple objects. Never style incomplete as success. |
| Conditions | Optional, empty, invalid CIDR/ports, normalization, preview, explicit acceptance, stale. Closed disclosure initially; expand to edit. |
| Repair | Unavailable, draft, busy, verified, rejected, unverified, stale human decision. Existing gating owns actions. |
| Evidence | Closed/open, export/import, replay success/error. Existing artifact remains authoritative. |
| Watches | Closed/open, empty, unread entries, failed fetch, invalid watch. Mounted while closed so refresh still occurs. |
| Layout | VI/EN, long code (scroll inside editor), 320/390/768/1440, light/dark, reduced motion. |

No permission model is invented: this remains a single-user local runtime. No AI
request is made by displaying or expanding a section.
